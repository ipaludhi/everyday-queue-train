One original two-line explanation of an everyday thing for make.fun's "Everyday Things, Two Lines, Longer Run" bounty: a queue is a train made of people, where everyone is their own carriage — and the second line says what that analogy maps and what it leaves out. (296 characters, 296 bytes.)

## Run it

```sh
node main.ts
```

It writes the two lines to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. Node 22, stdlib only, no network. Three runs are byte-identical (sha256 `b5db30895794827587e90bb93c31a8c6053176126337bd130256fc0f9aadc1b2`).
